# ⚡ SoundFlow Studio

**SoundFlow Studio** — современный многофункциональный аналог Soundpad для Windows, спроектированный для геймеров, стримеров и авторов контента. 

Помимо классического воспроизведения звуков по горячим клавишам, приложение умеет **в реальном времени стримить звук из любого запущенного приложения (браузера, плеера, игры) напрямую в микрофон**, проигрывать интернет-радиостанции, изменять голос (Voice Changer) и озвучивать текст нейросетью (Edge-TTS).

---

## 🚀 Ключевые возможности

1. **🎵 Саундборд нового поколения:**
   - Воспроизведение `.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a` без задержек.
   - Drag & Drop добавление файлов.
   - Категории звуков: Memes, Gaming, SFX, Clips.
   - Индивидуальная настройка громкости, скорости и питча каждого звука.
   - Глобальные горячие клавиши (хоткеи), работающие поверх любых полноэкранных игр.
   - Паническая кнопка `ESC` («Стоп всё»).

2. **🔀 Живой стрим звука из приложения прямо в микрофон (Live App Stream):**
   - Автоматическое обнаружение приложений, воспроизводящих звук (`chrome.exe`, `spotify.exe`, `telegram.exe`, игры).
   - Захват через высокоскоростной Windows WASAPI Loopback (<20 мс задержки).
   - Раздельное управление громкостью: для себя (динамики / наушники) и для тиммейтов (в микрофон).
   - Глобальный хоткей включения/выключения `Ctrl+F9`.

3. **📻 Встроенное интернет-радио (Web Audio Streams):**
   - Пресеты радиостанций: *Lofi Chill & Study*, *Nightride Synthwave*, *Radio Record Club*, *Rock Hits*, *DFM*.
   - Поддержка любого пользовательского Icecast / Shoutcast / Direct MP3 / AAC потока.
   - Живое отображение ICY-метаданных («Сейчас играет: Трек — Исполнитель»).

4. **🎙️ Голосовые эффекты в реальном времени (Voice Changer & Gate):**
   - Проброс физического микрофона через встроенный DSP.
   - Пресеты: *Helium Chipmunk* (бурундук), *Monster/Demon* (демон), *Cyber Robot* (робот), *Megaphone* (рация), *Space Echo* (эхо).
   - Адаптивный шумоподавитель (Noise Gate) с регулируемым порогом.

5. **🗣️ Нейросетевой Text-To-Speech (TTS):**
   - Озвучка текста на лету голосами Microsoft Neural (Дмитрий, Светлана, Guy, Jenny).
   - Трансляция речи прямо в микрофон в Discord / CS2 / Telegram.
   - Кнопка «Сохранить на Саундборд»: мгновенно превращает озвученную фразу в постоянную кнопку саундборда!

6. **⏺️ Моментальный повтор (Instant Replay Buffer):**
   - Циклический буфер последних 15 / 30 / 60 секунд системного звука.
   - Нажатие `Ctrl+F11` сохраняет записанный фрагмент в `.wav` и сразу добавляет его в саундборд!

7. **💻 Интеграция с Windows:**
   - Неоновый тёмный интерфейс (Dark Glassmorphism).
   - Сворачивание в системный трей при закрытии (продолжает работать в фоне).

## 🎧 Как настроить передачу в Discord / Игры (VB-Cable)

Чтобы собеседники в Discord, Telegram или играх слышали звуки:
1. Скачайте и установите бесплатный драйвер **VB-Audio Virtual Cable** с официального сайта: [vb-audio.com/Cable/](https://vb-audio.com/Cable/) (требуется разовая перезагрузка ПК).
2. Откройте **SoundFlow Studio** $\to$ **⚙️ Настройки**:
   - В поле **«Вывод в микрофон»** выберите `[Windows WASAPI] CABLE Input (VB-Audio Virtual Cable)`.
   - В поле **«Устройство мониторинга»** выберите ваши основные динамики / наушники.
   - В поле **«Твой реальный микрофон»** выберите ваш физический микрофон.
3. В настройках **Discord / игры**:
   - В качестве устройства ввода (микрофона) выберите `CABLE Output (VB-Audio Virtual Cable)`.
4. В SoundFlow во вкладке «Микрофон» нажмите **«Включить микрофон в миксер»**.

*Теперь и ваш голос с эффектами, и звуки саундборда, и стримы из приложений будут идти в идеальном качестве прямо в микрофон тиммейтам!*

## 🛠️ Запуск приложения

### Вариант 1 (Основной): Прямой запуск через EXE
Просто запустите файл **`SoundFlow.exe`** двойным кликом в папке:
```
O:\GitHub\SoundFlow\SoundFlow.exe
```

### Вариант 2: Запуск исходного кода через Python
```bash
cd O:\GitHub\SoundFlow
python run.py
```

## 🔌 Встроенный драйвер и статус
- Если драйвер виртуального кабеля еще не установлен на ПК, прямо вверху главного окна появится предупреждающий баннер с кнопкой **«Установить драйвер в 1 клик»**.
- Все вкладки, саундборд, радио и генератор речи остаются кликабельными и интерактивными (звук можно тестировать для себя — в динамиках или наушниках).
- Нажатие на кнопку установки запускает встроенный в приложение официальный инсталлятор `VBCABLE_Setup_x64.exe` с правами администратора.
- После установки нажмите **«Проверить снова»** — SoundFlow автоматически привяжет виртуальный кабель к микшеру!
